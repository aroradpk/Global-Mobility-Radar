# Phase 5A — private unified profile increment
The existing Profile and Answers remain canonical for job matching and planning. A separate current-age confirmation is intentionally date-sensitive (no birthdate collected); confirmed only for the assessment date, not automatically advanced. Country scenario linking is explicit and live: linked age updates on confirmation, becomes unknown on removal/date change, and unlink restores the independent manual draft. Canada/Australia/Germany Opportunity Card and age-bearing shared routes (Dutch HSM, NZ residence, HK QMAS, Singapore EP, UAE employment) reuse only this exact comparable fact. No auto mapping of legal credential recognition, citizenship/chargeability, language tests, employment periods, salary, employer evidence or sponsorship. No eligibility is inferred from a CV.
Manual career onboarding shares the same Review form. Placeholder legacy values cannot be committed until explicit years, career level, education and review confirmation. CV parsing remains heuristic, user must review; a review draft is committed only on Next; cancellation from dashboard preserves prior profile, snapshot and filters. Profile section displays reviewed career facts and current editable preferences; profile reset clears confirmed age and all scenarios. All data in tab memory, no storage/network/persistence or AI. Date expiry deliberately conservative; hypothetical age can be independently entered. Existing defaults in relocation preferences are planning defaults, not evidence. Manual skills/qualification unknowns remain limited by existing job profile schema (required years/level/degree), not passed into legal engines.
Remaining M01: richer structured evidence, occupation mappings, language test details, dependants, funds and work authorisation, explicit export and evidence lifecycle, full official mappings and parity; M09 comparison still not implemented. No module accepted. Browser tests cover profile link/update/removal, cancellation, manual onboarding, all prior flows and privacy. Candidate CI pending. No new runtime dependencies.


## Phase 5B evidence candidate
Seven categories in separate private local evidence editor. User explicitly reviews each record; optional fields are omitted rather than defaulted. Occupation code and classification must coexist, with no official code verification. Currency is only syntax-checked; individual language grades are self-reported, not converted into immigration thresholds. Expiry labels describe supplied dates only. Edit/cancel, delete and clear-all reset supported; export versioned JSON of saved evidence records only after confirmation. No import, persistence, remote processing, legal inference or automatic mappings beyond existing age. Complete profile export, official mapping and parity remain pending; 25 new unit cases and browser lifecycle regression authored; candidate CI pending.
